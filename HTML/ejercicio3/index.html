Enlaces e imágenes
<a> Enlace. Con href se indica a dónde lleva y con target="_blank" se abre en otra pestaña. <a href="url">Texto</a> Ir a MDN
<img> Muestra una imagen. src es la ruta y alt el texto alternativo. <img src="foto.jpg" alt="texto">

Formularios
<input type="checkbox"> Casilla que se puede marcar o desmarcar. <input type="checkbox">
<input type="radio"> Opciones de las que solo se puede elegir una (tienen el mismo name). <input type="radio" name="grupo">
<input type="password"> Campo para contraseñas: oculta lo que se escribe. <input type="password">
<textarea> Caja para escribir textos de varias líneas. <textarea rows="2"></textarea>
<button> Botón que se puede pulsar. <button type="button">Texto</button>
