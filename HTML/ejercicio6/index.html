¿Qué es?

Es una web sencilla para tener apuntadas todas las cosas pendientes, como los trabajos de clase o los exámenes, y llevar la cuenta de lo que ya está terminado.

¿Qué puedo hacer?

  1. Escribir una tarea nueva y añadirla a la tabla
  2. Marcar una tarea como hecha
  3. Cambiar el texto de una tarea
  4. Borrar una tarea que ya no necesito
  5. Visitar webs que ayudan a organizar el tiempo

Para empezar entra en Tareas.
